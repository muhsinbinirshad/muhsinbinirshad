### Hey, I'm Muhsin

I'm a pentester from Kerala. I got into security back in 2019, mostly because I wanted to know how
things break, and somehow that turned into a career. Seven years later I'm still learning something new
almost every week, which I've accepted is just how this field works. Anyone who says they've figured it
all out is either lying or selling a course.

My day job is offensive security. I test web apps, APIs, mobile apps, thick clients and infra, find the
stuff that shouldn't be there, and then write it up nicely so nobody feels too bad about it.

The other half of me is a developer. I build full stack products with Next.js, FastAPI and MongoDB,
mostly because I kept running into problems in security work that nobody had built a decent tool for.
And when I'm tired of screens, I design PCBs. Long story, keep reading.

**Quick facts**

- Pentester by profession, mostly offensive security
- Founder of [pentone.io](https://pentone.io)
- Co-founder of [captrit.ae](https://captrit.ae)
- Full stack dev: Next.js, FastAPI, MongoDB
- Designed the PCB badges for [c0c0n](https://c0c0n.org) for the last 2 years
- Travels solo whenever work allows

So I started PentOne, a SaaS tool that helps VAPT teams put their reports together around 15x faster.

### Open source

<p align="center">
  <a href="https://github.com/captrit/netmap"><img src="https://github-readme-stats.vercel.app/api/pin/?username=captrit&repo=netmap&hide_border=true&bg_color=0D1117&title_color=00D9FF&text_color=C9D1D9&icon_color=00D9FF&show_owner=true&description_lines_count=2" alt="captrit/netmap" /></a>
</p>

**[NetMap](https://github.com/captrit/netmap)** is a network discovery and topology mapping tool we built at Captrit.
You point it at a subnet and it sweeps it fast, fingerprints whatever is alive (printers included, because
there's always a printer), flags the usual misconfigs like unauthenticated databases, open SMB shares and
anonymous FTP, and streams everything live into a web UI. Works behind WireGuard and Tailscale too, and
exports to JSON, CSV or Nmap-style XML so it plays nice with the rest of your workflow.

Basically the thing I wanted on every internal pentest, so we made it.
