### `01 / ABOUT`

I'm a cybersecurity professional and software builder focused on offensive security, security automation, and tools that make security work more effective.

My interests sit at the intersection of **penetration testing, software engineering, and product development**. I enjoy understanding how systems fail, investigating vulnerabilities, automating repetitive workflows, and building software around real-world security problems.

I don't want to stop at running existing tools. I want to understand their internals, build better workflows, and engineer solutions that other security professionals can use.

- `OFFENSIVE SECURITY` — Web, API, mobile, and infrastructure security testing.
- `ENGINEERING` — Python, backend development, APIs, and automation.
- `PRODUCTS` — Building tools and workflows for penetration testers.
- `RESEARCH` — Reconnaissance, vulnerability analysis, and AI-assisted security.
- `PHILOSOPHY` — Fundamentals first. Evidence over assumptions. Build to learn.

#### PentOne — Security work, engineered.

I'm building **PentOne**, a product focused on making penetration-testing workflows more efficient.

The idea is to reduce the administrative overhead around security assessments, so testers can spend more time investigating vulnerabilities and less time managing repetitive reporting work.

Areas of focus include:

- Dynamic penetration-testing report generation.
- Structured findings, evidence, and remediation workflows.
- Reusable reporting templates and security knowledge.
- Collaboration and assessment management.

**Explore:** [pentone.io](https://pentone.io)
